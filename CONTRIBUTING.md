# Contributing

Thanks for your interest in Noctalia Dock App Customizer!

## Before opening an issue

Please check existing issues and include:

- Linux distribution and version;
- Noctalia version;
- application installation source (native package, Flatpak, Snap, etc.);
- application desktop-file ID and path;
- relevant logs, with usernames and other personal information removed.

## Changes

1. Keep changes focused and explain the user-visible impact.
2. Do not modify system desktop-entry files.
3. Never overwrite or delete pre-existing user-managed launchers.
4. Cleanup must be restricted to files explicitly tracked as created by this project.
5. Avoid adding dependencies unless they are necessary and documented.
6. Update both Russian and English documentation when behaviour or setup changes.

## Pull requests

Describe the problem, the approach, how you tested it, and any distribution-specific assumptions. Do not claim compatibility that has not been tested.
